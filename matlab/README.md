# MATLAB

`grape_target_states.m` (original name `theoretical_states.m`) lists the target density matrices `params.rhogoal`
used to optimise the GRAPE state-preparation pulses for each prepared state (paper Sec. III D: "pulses … optimised
with the help of the GRAPE package"). Each block is one state, commented in or out by hand, in the convention
"after tomography pulses". It is a configuration fragment for the lab's GRAPE code, which is not included.
